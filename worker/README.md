# Worker «живых» курсов
Cloudflare Worker: по запросу берёт курс ЦБ и курсы банков Калининграда и отдаёт JSON (формат как `data/rates.json`).
Ответ кэшируется на 2 минуты. Деплой — через Workers Builds (корневая папка сборки: `worker`).
После деплоя вставьте адрес Worker в константу `LIVE` в `index.html`.
